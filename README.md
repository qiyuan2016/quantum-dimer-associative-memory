# Quantum Dimer Associative Memory

This repository contains the numerical simulation code accompanying our research on quantum associative memory using valence-bond (dimer) states.

We study a quantum generalization of the Hopfield associative memory model, in which information is encoded in pairings of spin-1/2 particles into singlets. The repository includes implementations of the quantum dimer model and classical Hopfield benchmarks used to investigate memory stability, storage capacity, and ground-state properties.

## Repository Structure

```text
.
├── src/                  # Numerical simulation code
├── data/                 # Example numerical dataset
├── figures/              # Example figure
├── requirements.txt      # Python dependencies
└── README.md
```

The `src/` directory contains scripts for the numerical calculations presented in the accompanying work.

Due to the size of the numerical datasets, only one representative dataset and its corresponding figure are included in this repository. The remaining scripts are provided to document the numerical methods and allow the calculations to be reproduced.

## Installation

The code is written in Python and uses NumPy, SciPy, Matplotlib, and QuTiP.

Install the dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Example: Local Stability of Dimer Memories

As an example, we provide the data and figure generated by `src/dimer_error_rate.py`.

This script estimates the probability that a stored dimer memory is locally unstable under a two-spin perturbation.

For each system size \(N\) and number of stored memories \(K\), the simulation generates random memory configurations and tests their local stability. The error rate is estimated as the fraction of sampled realizations in which the selected memory is unstable.

The results are stored in:

```text
data/dimer_error_rates.pkl
```

The corresponding figure is saved as:

```text
figures/dimer_error_rates.pdf
```

To rerun the example calculation from the repository root:

```bash
python src/dimer_error_rate.py
```

**Note:** Rerunning the script may overwrite the included example dataset and figure. The runtime depends on the system sizes, memory counts, and number of Monte Carlo samples specified in the script.

## Data Availability

The repository includes a representative numerical dataset and figure. Other numerical datasets are not included due to their large file sizes.

The source code for the numerical simulations is provided to facilitate reproducibility of the results.
